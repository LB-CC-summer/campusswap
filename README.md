# 校易集 CampusSwap

广东工业大学软件工程课程团队项目 · **拾集小队**

面向广工在校学生的校园二手交易平台，内嵌智能交易助手：买家说一句"我想买宿舍写代码用的显示器，300 以内，只要大学城校区"，就能拿到真实在售的商品清单、推荐理由与缺失信息提示；卖家拍张照片说一句话，就能拿到一份可以直接改的发布草稿。全程在平台内沟通，不公开手机号与微信。

## 覆盖校区

大学城、东风路、龙洞、番禺、揭阳（沙河校区暂未列入，后台可随时扩展）

## 核心功能

| 模块 | 说明 |
|---|---|
| 账号与个人中心 | 注册登录、校内身份认证、校区设置 |
| 商品集市 | 发布、分类浏览、条件筛选、详情、状态管理 |
| 智能找物 | 自然语言条件抽取、多轮修改、真实商品检索、推荐解释 |
| 智能发布 | 图片 + 一句话 → 追问 → 可编辑草稿 |
| 站内沟通与隐私 | 站内聊天、联系方式交换申请、敏感信息打码、拉黑举报 |
| 沟通与交易 | 交易申请、卖家确认、双方确认完成 |
| 基础后台 | 用户、校区、商品、举报管理 |
