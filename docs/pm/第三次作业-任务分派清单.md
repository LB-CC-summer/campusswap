## 一、一句话说清这轮干什么

仓库现在有 8 份文档、12 张 UML、23 张截图、16 张表的建库脚本，**但一行业务代码都没有**。所以冲刺只做一件事：把它跑起来，做成外网能打开的可用版本。

本期只做一条主链路：**注册登录 → 集市浏览筛选 → 商品详情 → 发布商品（含图片）→ 智能找物（含降级）**。
聊天、交易闭环、后台五页**不做**，推到 beta（原计划第 14–15 周），答辩时如实说明。

## 六、规矩（五条，照做即可）

1. **每人自己提 commit，PR 自己提。** 代提交会让本人在 `main` 上零提交，助教按人查贡献直接扣分。
2. **不直接推 `main`。** `feat/xxx` → PR → `develop`；`main` 始终可演示。
3. **接口变更先改 `docs/03` 再改代码**，群里同步一句，否则前端必然返工。
4. **站会 10 分钟**：昨天做完什么、今天做什么、卡在哪。细节另约，不在会上讨论。
5. **材料当天留痕**：站会记录当天写、vlog 素材当天拍、燃尽图当天记。事后补不出来。
