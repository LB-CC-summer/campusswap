## 导出 PDF 的命名

课程要求提交 PDF，文件名必须是「团队名称_文档名.pdf」：

- `拾集小队_系统设计说明书.pdf`
- `拾集小队_数据库设计说明书.pdf`

不要用 `01-系统设计说明书.pdf` 这类内部编号命名，评审按团队名称找文件。

## 排版规范

全部正式文档统一以下格式，避免合稿时返工：

| 项目 | 规范 |
|---|---|
| 正文字体 | 小四（12pt）宋体，西文 Times New Roman |
| 行距 | 1.5 倍 |
| 一级标题 | 三号黑体加粗 |
| 二级标题 | 四号黑体加粗 |
| 图表题注 | 五号宋体，图题在下、表题在上 |
| 页码 | 页脚居中，正文起编 |
| 缩写 | 首次出现必须给出全称，正文 1.3 节有汇总表 |

## 两份文档的分工边界

**这是最容易出错的地方，也是助教会逐字比对的地方：**

- **表结构只在《数据库设计说明书》里写全。** 系统设计说明书第 5 章只给 16 张表的清单、分组意图与关键约束，字段定义一律引用 DBDD，不重复列表。两份文档同一字段名写法不一致，是评审最常抓的问题。
- **接口参数只在《核心接口设计说明书》里写全。** 系统设计说明书 4.2/4.3 只给核心接口摘要与错误码，用于判断设计是否可实现，完整定义引用接口文档。
- **图的编号只在系统设计说明书里定义。** 其他文档引用图时使用「见图 2-4」的形式，不自行编号。
