# 链接检查表

> 维护人：廖炳程（运维 / 部署 + 测试）
> 用途：第二次团队作业提交前，对外链逐一验证。**每条都必须用无痕窗口验证**，在有登录态的浏览器里能打开不算数。
> 更新时间：2026-11-21

## 为什么必须用无痕窗口

作业原文："注意审查链接是否能被其他人正常访问"。

在自己的浏览器里能打开，可能只是因为：
- 你登录着 Figma / 腾讯文档 / 云盘，看的是自己的资源
- 你浏览器里有缓存
- 本地有 ssr 或代理

助教用的是新环境、未登录、可能手机。三种情况都可能打不开，而原型占 40% 分。

## 逐条验证步骤

### 1–2 Figma 原型

1. 打开 Chrome / Edge 无痕窗口（`Ctrl + Shift + N`）
2. 粘贴链接，确认：
   - 不弹「请求访问权限」对话框
   - 不跳转登录页
   - 能看到画板，且可以点热区跳转
3. 用手机扫码或直接打开链接，确认画板不被裁切、文字可读
4. 截图存档（放 `docs/links/` 目录）

**Figma proto 链接的常见坑：**
- 分享设置是「仅自己」→ 必须改成「获得链接的任何人」
- 用的是 `/design/` 而非 `/proto/` 链接 → 展示模式打不开热区
- `node-id` 参数指向已删除的画板 → 打开是空白

### 3 GitHub 仓库

1. 无痕窗口打开 `https://github.com/LB-CC-summer/campusswap`
2. 确认仓库为 `Public`，不要求登录
3. 确认 `docs/`、`docs/uml/`、`docs/prototype/` 都能点进去

### 4–5 PDF 文档

仓库内直链形如：
```
https://github.com/LB-CC-summer/campusswap/blob/main/docs/01-系统设计说明书.pdf
```

GitHub 会在浏览器内置预览 PDF。若文件过大或中文嵌入异常，改用 `raw` 链接：
```
https://raw.githubusercontent.com/LB-CC-summer/campusswap/main/docs/01-系统设计说明书.pdf
```

**验证要点：**
- 中文不乱码（不是方框或问号）
- 表格没有溢出页面
- 图片不是模糊的缩略图
- 页码与目录对得上

### 6 博客链接

发布后回填。验证：无痕窗口可读，且博客头部五个必填字段齐全（课程 / 要求 / 目标 / 团队名称 / 成员）。

## 已知风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| Figma 链接需要登录 | 原型 40% 直接归零 | 改成「获得链接的任何人」，用无痕窗口复验 |
| PDF 中文乱码 | 文档不可读，等同于没交 | 导出时嵌入字体（宋体 / 思源宋体），不要用系统缺失字体 |
| GitHub 仓库意外设为私有 | 助教看不到任何东西 | 交接前截图确认 Public |
| 云盘链接带提取码但博客没写 | 打不开 | 要么去掉提取码，要么把提取码写进博客正文 |
| 博客只在团队博客可见 | 部分班级要求发在班级博客 | 确认老师要求，必要时两处都发 |
