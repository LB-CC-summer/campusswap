## 五、超出要求的设计（评审加分项）

以下几处不在需求文档的硬性要求里，是 UI 主动补的：

1. **校区不一致拦截浮层** —— 把「校区是硬条件」这条规则，变成了用户能看懂的一句话 + 两个出口
2. **面交地点建议** —— 「优先选择图书馆公共区域、食堂入口或教学区广场，请勿发送宿舍楼、房间号」
3. **隐私与安全浮层** —— 三条承诺 + 拉黑/举报入口
4. **交易如何完成的分步说明** + 「同一商品同一时间只有一笔有效交易」
5. **对比页的「未填写」vs「—」图例** —— 区分"卖家没填"和"该维度不适用"，避免误解
6. **AI 对比分析** —— 跨商品给出一句话结论
